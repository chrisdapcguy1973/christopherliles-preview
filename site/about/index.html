Christopher Liles

Senior Tier 3 Product Solutions Engineer

Christopher Liles is a Senior Tier 3 Product Solutions Engineer with 25+ years in IT spanning MSP security tooling, systems administration, and support. At CyberFOX he owns Tier 3 escalations across privileged access management, password management, DNS filtering, SASE/zero trust network access, and Microsoft 365 security platforms, serves as liaison to each product's development team, and backs up DevOps. He brings deep Microsoft 365, Windows Server, Active Directory, VMware, and networking experience. This site is a working notebook for that practice: field notes, homelab topology, and a clear picture of the stack behind the work.
